# 퇴근길 마감 데모 · 팀 페이즈

빵집, 반찬가게, 만두집처럼 오늘 못 팔면 버려지는 동네 가게의 마감 상품을 AI 에이전트끼리 사고파는 서비스의 시연용 데모입니다.
처음 화면에서 사장님으로 시작할지, 구매자로 시작할지 고를 수 있습니다. 모든 데이터는 예시입니다.

## 구조

- `server.js` Express 백엔드. `/api/seller`, `/api/buyer`, `/api/pay`, `/api/health`
- `public/engine.js` 판매자 가격 책정, 구매자 추천 점수, 지갑 결제 로직. 서버와 브라우저가 같은 파일을 씁니다.
- `public/app.js` 화면. 서버가 있으면 API로 계산하고, 없으면 브라우저에서 같은 엔진으로 계산합니다.

## 로컬 실행

```
npm install
npm start
```

http://localhost:3000 에서 열립니다.

## GitHub Pages 배포

`public` 폴더만 올리면 정적 페이지로 동작합니다. 서버가 없을 때는 브라우저 엔진으로 같은 흐름이 돌아갑니다.
백엔드까지 띄우려면 Render 같은 Node 호스팅에 올리고, 잠들지 않도록 `/api/health`를 주기적으로 호출하면 됩니다.
